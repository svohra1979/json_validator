# JSON Validator

A simple, lightweight web-based tool for validating and formatting JSON data.

## Features

- Real-time JSON validation
- Formatted output display for valid JSON
- Clear error messages with line details
- Responsive, modern user interface
- No external dependencies required

## Usage

1. Open `index.html` in a web browser
2. Paste JSON content into the input textarea
3. Click the "Validate" button
4. View validation results and formatted output

## Project Structure

- `index.html` - Application markup
- `script.js` - Validation logic and event handling
- `style.css` - Styling and layout

## Validation

The tool uses the native JavaScript `JSON.parse()` method to validate input. Valid JSON is displayed in formatted (pretty-printed) form with 2-space indentation.

## Browser Compatibility

Compatible with all modern browsers supporting ES6 JavaScript.
